AK SELLER — WhatsApp Order Edition (Free)

इस ZIP में index.html है। यह GitHub Pages पर चलने वाली static website है और ग्राहक के चुने हुए products को WhatsApp message में बदलती है।

महत्वपूर्ण:
- इसमें दिए गए 4 products अभी डेमो हैं। असली बिक्री से पहले नाम, कीमत, फोटो/विवरण, उपलब्धता और सप्लायर की पुष्टि करें।
- ग्राहक के WhatsApp संदेश तभी आपके पास आएँगे जब आप सही WhatsApp नंबर देश कोड सहित सेट करेंगे।
- Settings में नंबर और जोड़े गए products उस मोबाइल/ब्राउज़र के localStorage में सेव होते हैं। दूसरे ग्राहकों के लिए admin से बदलने वाला साझा database नहीं है।
- कोई ऑनलाइन payment gateway, inventory database, secure admin login या automatic delivery integration नहीं है।
- PIN केवल साधारण स्थानीय रोक है; इसे सुरक्षित प्रमाणीकरण न समझें।

मोबाइल से GitHub Pages पर अपडेट करने का तरीका:
1. GitHub में अपनी repository खोलें (वही जिसके लिंक में github.io आता है)।
2. repository की फाइल सूची में index.html खोलें।
3. पेंसिल (Edit) दबाएँ। अगर पेंसिल नहीं दिखती, तो Code टैब/फाइल सूची में index.html खोलकर तीन-बिंदु मेन्यू देखें।
4. पुराना पूरा कोड चुनकर हटाएँ और ZIP में दिए गए index.html का पूरा कोड पेस्ट करें।
5. नीचे/ऊपर Commit changes दबाएँ, फिर Commit changes की पुष्टि करें।
6. 1–5 मिनट बाद github.io वेबसाइट को Chrome में खोलें। पुराना पेज दिखे तो Chrome refresh करें या Incognito में जाँचें।
7. वेबसाइट के सबसे नीचे © वर्ष / AK SELLER वाली footer लाइन पर लगातार 5 बार टैप करें।
8. WhatsApp नंबर में 91 के बाद अपना 10-अंकों का नंबर लिखें (कुल 12 अंक, उदाहरण: 91XXXXXXXXXX; असली नंबर अपना डालें)। पहली बार PIN बनाएँ और सेव करें।
9. यह PIN/नंबर उसी browser में सेव होता है। इसलिए पहले अपने मोबाइल पर टेस्ट ऑर्डर करें। WhatsApp खुलने पर संदेश पढ़कर ही Send दबाएँ।

नोट: यदि repository में index.html किसी subfolder में है या GitHub Pages अलग branch/folder से प्रकाशित है, तो उसी प्रकाशित folder की index.html बदलें।
